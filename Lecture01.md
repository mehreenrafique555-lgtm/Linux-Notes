# Kali Linux

---

## Kali Linux Kya Hai

### 1. Introduction

- **Kali Linux** ek **Linux operating system** hai, jo **Debian Linux** par bana hua hai.
- Ye khaas taur par **cybersecurity, ethical hacking aur penetration testing** k liye banaya gaya hai.
- Isko **Offensive Security (OffSec)** company maintain karti hai.
- Ye **free aur open source** hai, yani koi bhi download karke use kar sakta hai.
- Is me **600 se zyada security tools** pehle se installed aate hain.
- *Misal:* Jaise **Windows** normal kaam k liye hai, waise **Kali Linux** security testing k liye hai.

### 2. Penetration Testing kya hota hai

- Kisi system ya network par **permission lekar attack karke dekhna**, taake uski **kamzoriyan (weaknesses)** pata chal jayein.
- Phir un kamzoriyon ko **theek (fix)** kiya jata hai, is se asli hackers se bacha ja sakta hai.
- *Misal:* Company apni website ki security check karwane k liye **ethical hacker** hire karti hai.

---

## Kali Linux Ka Use Kyun Hota Hai

### 1. Tools pehle se ready

- Hacking aur security ke **tools alag alag install nahi karne parte**, sab ek hi jagah mil jate hain.
- Is se **time bachta hai** aur setup aasan hota hai.

### 2. Seekhne k liye

- **Cybersecurity students** is par practice karte hain.
- Is se **Linux commands** (`ls`, `cd`, `cat`, `grep` waghera) ki practice bhi hoti hai.

### 3. Security testing k liye

- **Network, website aur device** ki security check karne k liye.
- **Logs** aur system ki activity analyze karne k liye.
- **Weak passwords** aur kamzoriyan dhoondhne k liye.

### 4. Kya Kali Linux zaroori hai?

- **Zaroori nahi hai**, lekin cybersecurity seekhne walon k liye **bohat helpful** hai.
- Ye tools kisi aur Linux par bhi install ho sakte hain, lekin Kali me **sab pehle se tayyar** hote hain.

---

## Kali Linux Install Kaise Karte Hain

### 1. Virtual Machine (Best Tareeqa)

- **VirtualBox** ya **VMware** me Kali install karo.
- Is se aap ka **asli Windows safe** rehta hai.
- Beginners k liye ye **sab se behtar** option hai.

### 2. Dual Boot

- Laptop me **Windows ke saath Kali** bhi install hota hai.

### 3. Live USB

- USB se **bina install kiye** chala sakte hain.

---

## Zaroori Baatein

### 1. Legal Warning ⚠️

- Kisi ka system, WiFi ya account **permission ke bagair test karna jurm hai** aur is par **saza** ho sakti hai.
- Practice sirf **apne device ya lab** me karo.

### 2. Daily use k liye nahi

- Kali **normal roz ke kaam** (browsing, documents) k liye nahi banaya gaya.
- Ye **sirf security testing** k liye hai.

### 3. Terminal ka use

- Kali me zyada kaam **CLI (terminal)** me hota hai.
- Isi liye **Linux commands** seekhna bohat zaroori hai.
